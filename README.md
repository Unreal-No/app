# Mochimon — Desktop Hybrid Virtual Pet

สัตว์เลี้ยงเสมือนที่อาศัยอยู่บนหน้าจอ Desktop ของคุณ (แนว Tamagotchi × Monster Farm, **ไม่มีการต่อสู้**)
เน้นความน่ารัก การเลี้ยงดู การผสมพันธุ์ข้ามสายพันธุ์ และการเป็นเพื่อนที่มีประโยชน์จริงระหว่างทำงาน

> สถานะ: เลี้ยงได้หลายตัว ผสมพันธุ์ เกาะขอบหน้าต่าง ผู้ช่วยทำงาน ปฏิทิน และคุยกับสัตว์ด้วย AI — ลองบน Windows จริงแล้ว
> ตอนนี้: **M2 "วงจรยีนส์"** (อัญเชิญจากไฟล์ สมุดฟาร์ม เครือญาติ สมุดสะสม) + **M3 "โลกและการผจญภัย"**
> (บิน คอนโดตู้ปลา กลางวัน-กลางคืน เทศกาล ส่งสำรวจ แขกป่า ความสัมพันธ์) ดู [docs/ROADMAP.md](docs/ROADMAP.md)

## โครงสร้าง

| โฟลเดอร์             | เนื้อหา                                                                             |
| ------------------- | --------------------------------------------------------------------------------- |
| `packages/data`     | Gene DB: locus, allele, สายพันธุ์ตั้งต้น (JSON + ตรวจด้วย zod)                           |
| `packages/core`     | แกนเกม TypeScript ล้วน: ยีนส์ ผสมพันธุ์ กลายพันธุ์ อัญเชิญจากไฟล์ รูปร่าง อารมณ์ นิสัย Behavior AI |
| `packages/creature` | ตัวสร้างสัตว์ 3D แบบ procedural ด้วย three.js (ผิวตุ๊กตา ขนฟู ใบหน้า ท่าทาง)                 |
| `apps/lab`          | Creature Lab — หน้าเว็บสำหรับดู/ผสม/อัญเชิญสัตว์ ใช้ปรับหน้าตาและทดสอบ                       |
| `packages/habitat`  | ฉากไดโอรามาแบบ procedural 4 แบบ (ทุ่งหญ้า เกาะเมฆ ใต้น้ำ หิมะ)                          |
| `apps/desktop`      | แอป Desktop (Tauri 2): หน้าต่างโปร่งใส คลิกทะลุ สัตว์เดินบน Taskbar และขอบหน้าต่าง แผงดูแล   |
| `tools/art-bakery`  | สคริปต์ทดลองสร้างโมเดลด้วย Blender แบบไม่มีหน้าจอ                                        |
| `docs`              | เอกสารออกแบบ                                                                      |

## เริ่มใช้งาน

ต้องมี Node 22+ และ pnpm 10+

```bash
pnpm install
pnpm test          # unit test ของแกนเกม
pnpm typecheck
pnpm lab           # เปิด Creature Lab ที่ http://localhost:5173 (หน้า Style Sheet: /stylesheet.html)
```

แอป Desktop (ต้องมี Rust และ Windows 10/11 ที่มี WebView2):

```bash
pnpm desktop        # โหมดพัฒนา
pnpm desktop:build  # สร้างตัวติดตั้ง
```

ฉาก overlay เปิดในเบราว์เซอร์ธรรมดาได้ด้วย `pnpm --filter @mochimon/desktop dev` (พอร์ต 1420)
โดยจะใช้ค่าจำลองแทนส่วนที่ต้องพึ่ง Windows

## วิธีเล่น (แอป Desktop)

| ทำอะไร                         | ผล                                                                                              |
| ------------------------------ | ----------------------------------------------------------------------------------------------- |
| คลิกที่สัตว์                        | ลูบ (ลูบไข่ช่วยให้ฟักเร็วขึ้น)                                                                           |
| ลากสัตว์                         | อุ้มไปวางที่อื่น — ปล่อยเหนือหน้าต่างโปรแกรมอื่นจะเกาะบนขอบ                                                 |
| คลิกขวาที่สัตว์                     | แผงดูแล: สถานะ อาหาร ขนม เล่น อาบน้ำ นอน ตั้งชื่อ จับคู่ ฝากฟาร์ม                                          |
| ไอคอนใน system tray (มุมขวาล่าง) | ผู้ช่วย, เริ่มโฟกัส, เรียกมาหา, อัญเชิญจากไฟล์, สมุดฟาร์ม, รับไข่ใบใหม่, ฉากมุมพักผ่อน, โหมดเงียบ, เปิดพร้อม Windows |

**ผู้ช่วยทำงาน** (tray → ผู้ช่วย หรือปุ่ม "ผู้ช่วย" ในแผงดูแล):

- **เตือน:** พิมพ์ภาษาพูด เช่น `14:30 ประชุม`, `อีก 20 นาที โทรหาแม่`, `ทุกวัน 12:00 กินข้าว` แล้วกด Enter — สัตว์จะบอกล่วงหน้า 10/5/1 นาที และถือป้ายเดินมาเมื่อถึงเวลา
- **งาน:** รายการสิ่งที่ต้องทำ ติ๊กเสร็จแล้วสัตว์ดีใจด้วย
- **โฟกัส:** จับเวลา 25/5 นาที สัตว์นั่งเป็นเพื่อนเงียบๆ และไข่ฟักเร็วขึ้น
- **คุยกับสัตว์:** ปุ่ม "💬 คุย" ในแผงดูแล — คุยแบบง่ายได้ทันที หรือเปิด AI ด้วย API key ของ Claude (เก็บใน Windows Credential Manager) หรือ Ollama ในเครื่อง สัตว์ช่วยตั้งเตือน จดงาน ดูนัด และเริ่มโฟกัสจากการคุยได้
- **ปฏิทิน:** วางลิงก์ปฏิทินแบบ ICS ของ Google ("ที่อยู่ลับในรูปแบบ iCal") หรือ Outlook ("เผยแพร่ปฏิทิน") — สัตว์เตือนก่อนประชุมและเงียบระหว่างประชุม (ลิงก์เก็บในเครื่องเท่านั้น)
- **สุขภาพ:** เตือนพักสายตา ดื่มน้ำ ยืดเส้น และดึกแล้ว (ปิดไว้ เลือกเปิดเอง)

**อัญเชิญจากไฟล์** (tray → อัญเชิญจากไฟล์…): ลากไฟล์จาก Explorer มาวางบนวงเวท หรือกด "เลือกไฟล์…" — รูปภาพให้สีตามภาพ
ไฟล์เก่ากว่า 8 ปีได้ไข่ฟอสซิล ไฟล์เดิมได้ไข่แบบเดิมเสมอ อัญเชิญได้ไฟล์ละครั้ง วันละ 3 ครั้ง (ใช้แค่ลายนิ้วมือของไฟล์ ไม่เก็บหรือส่งไฟล์ออกจากเครื่อง)

**สมุดฟาร์ม** (tray หรือปุ่ม "🌳 สมุด" ในแผงดูแล): ดูและเรียกตัวที่ฝากไว้ (จอเต็มเลือกสลับได้), ผังเครือญาติ 3 รุ่น,
สมุดสะสมลักษณะที่ค้นพบแยกตามความหายาก (✨ = ได้จากการกลายพันธุ์เท่านั้น)

**โลกรอบตัว:** สัตว์มีปีกบินเล่น สัตว์น้ำอยู่คอนโดตู้ปลาหลายชั้น (ลากปลาเพื่อย้ายคอนโด) แสงเปลี่ยนตามเวลาจริง (ปิดได้ใน tray) มีหิ่งห้อยตอนกลางคืนและเทศกาลไทย

**ส่งสำรวจ** (ปุ่ม "🧭 สำรวจ" ในแผงดูแล): 15 นาที–8 ชม. ตามเวลาจริง กลับมาพร้อมของพิเศษ ไข่ หรือชิ้นฟอสซิล (ครบ 3 ชิ้นประกอบเป็นไข่ได้ในสมุดฟาร์ม)

**แขกป่า:** ทุก 1–2 ชั่วโมงอาจมีสัตว์ป่าเดินผ่าน — คลิกแล้วให้ของที่มันคิดถึง (ดูฟองความคิด) เพื่อชวนมาอยู่ด้วย
สัตว์ที่อยู่ด้วยกันนานๆ จะเป็นเพื่อนซี้ แอบชอบ หรือคู่กัด ตามนิสัย

**ชิ้นส่วน 3D ของคุณเอง** (tray → นำเข้าชิ้นส่วน 3D): เปลี่ยนหู เขา ปีก หาง ด้วยไฟล์ .glb ที่ทำใน Blender
(ให้ ChatGPT เขียนสคริปต์ได้) — วิธีทำ: [docs/PARTS_GUIDE.md](docs/PARTS_GUIDE.md), ไฟล์ตัวอย่าง: `tools/parts-kit/example-parts.glb`

**มังกรไฟ** (สายพันธุ์ที่ 8, สายเทพนิยาย): เทอร์ควอยส์ ท้องครีม ปีกส้ม — เจอได้จากอัญเชิญ แขกป่า และสำรวจเกาะเมฆ
ใช้คู่กับชุดชิ้นส่วน `tools/parts-kit/fire-dragon-parts.glb` (หูใบไม้ เขาโค้ง ปีกค้างคาว หางมังกร ที่ออกแบบด้วย GPT)

สัตว์โตตามเวลาที่คุณอยู่หน้าจอ และโตถึงวัยรุ่นแล้วจับคู่กันได้ บนจออยู่ได้พร้อมกัน 4 ตัว ที่เหลือฝากไว้ที่ฟาร์ม
เซฟอัตโนมัติลงโฟลเดอร์ข้อมูลของแอป (`%APPDATA%\app.mochimon.desktop\save.json` พร้อมสำเนาสำรอง 3 รุ่น)
