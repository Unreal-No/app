# Genetics — ระบบยีนส์และการผสมพันธุ์

โค้ด: `packages/core/src/genetics/`, ข้อมูล: `packages/data/src/`, ทดสอบ: `packages/core/test/genetics.test.ts`

## โครงสร้าง genome

สัตว์ทุกตัวเป็น **diploid**: ทุก locus มี allele 2 ตัว (จากพ่อ 1 แม่ 1) และ**ทุกสายพันธุ์ใช้ชุด locus เดียวกัน**
จึงผสมข้ามสายพันธุ์ได้ทุกคู่ — สายพันธุ์เป็นเพียง "ชุด allele ที่พบบ่อย" ไม่ใช่ชนิดที่แยกขาดจากกัน

```ts
interface Genome {
  v: 1
  genes: Record<LocusId, [Allele, Allele]>
  ancestry: Record<SpeciesId, number> // สัดส่วนบรรพบุรุษ รวมกัน = 1
  generation: number
}
```

## Lineage และสายพันธุ์ตั้งต้น

| Lineage  | สายพันธุ์                   |
| -------- | ------------------------ |
| ปัจจุบัน    | แมว กระต่าย นกน้อย ปลาคาร์ป |
| ดึกดำบรรพ์ | ไทรเซอราทอปส์             |
| เทพนิยาย  | มังกร ยูนิคอร์น              |

เพิ่มสายพันธุ์ใหม่ได้โดยเพิ่มไฟล์ใน `species/` (และ allele ใหม่ถ้าต้องการ) โดยไม่ต้องแก้โค้ดแกนเกม

## การผสมพันธุ์ (`breed`)

1. **สร้างเซลล์สืบพันธุ์**: แต่ละฝ่ายส่ง allele 1 ตัวต่อ locus
   - locus ที่ไม่มี linkage: สุ่ม 50/50 อิสระ
   - locus ในกลุ่ม linkage เดียวกัน (เช่น ทรงหัว+ชนิดหู+ขนาดหู): มักไปด้วยกัน โอกาสไขว้เปลี่ยน 25% ต่อ locus
2. **กลายพันธุ์** (ค่าเริ่มต้น 2.5% ต่อ allele ที่ถ่ายทอด)
   - ตัวเลข: ขยับค่าแบบ Gaussian · สี: เลื่อน hue/ความสว่าง
   - part: 80% สลับเป็น allele ปกติตัวอื่นของ locus, 20% ได้ allele พิเศษ (`mutationOnly`)
3. `ancestry` ของลูก = ค่าเฉลี่ยของพ่อแม่, `generation` = รุ่นที่มากกว่า + 1

**allele พิเศษที่ได้จากการกลายพันธุ์เท่านั้น:** เรืองแสง · ผิวคริสตัล · สีรุ้ง · สองหาง · เขาคริสตัล
(ลักษณะพิเศษเป็นยีนส์ด้อย: ต้องได้ครบ 2 ชุดจึงแสดงออก → กลายพันธุ์แล้วได้ "พาหะ" ต้องผสมต่อจึงเห็นผล)

### สิ่งที่ทดสอบยืนยันแล้ว

- Aa × Aa ได้ลักษณะด้อย ≈ 25% (อัตราส่วนเมนเดล 3:1) จาก 4,000 ครั้ง
- ยีนส์ด้อยที่ซ่อนในรุ่นลูกกลับมาแสดงออกในรุ่นหลาน
- ไม่มี mutation → ลูกได้ allele จากพ่อและแม่ฝ่ายละ 1 ตัวเสมอ
- ผสมได้ครบทุกคู่สายพันธุ์ (7×7) และลูกเป็น genome ที่ถูกต้อง
- linkage ทำให้ locus ในกลุ่มเดียวกันไปด้วยกัน ≈ 75%
- seed เดียวกันได้ผลเดิมทุกครั้ง

## ชื่อชนิดของลูกผสม

`speciesLabel` ใช้ชื่อสายพันธุ์ถ้าเป็นพันธุ์แท้ ถ้าสายพันธุ์อันดับสองมีสัดส่วน ≥ 20% จะประกอบพยางค์จากสองสายพันธุ์หลัก
เช่น แมว×มังกร → "Miodrake" (ชื่อเดิมเสมอสำหรับคู่สายพันธุ์เดียวกัน)

## อัญเชิญจากไฟล์ (`summonFromFile`)

ชั้นนอก (Rust/WebCrypto) อ่านไฟล์แล้วส่งเฉพาะ **hash SHA-256, ขนาด, นามสกุล, อายุไฟล์ และสีเด่นของรูป** เข้ามา
แกนเกมไม่เห็นเนื้อหาไฟล์ และข้อมูลไม่ออกจากเครื่อง

| ลักษณะไฟล์ | ผล                                           |
| -------- | -------------------------------------------- |
| hash     | seed ของการสุ่มทั้งหมด → ไฟล์เดียวกันได้สัตว์ตัวเดิมเสมอ |
| ขนาด     | ขนาดตัว (1KB เล็ก → 1GB ใหญ่สุด)                 |
| อายุ      | ยิ่งเก่ายิ่งมีโอกาสได้สายดึกดำบรรพ์; ≥ 8 ปี = ไข่ฟอสซิล  |
| รูปภาพ    | สีเด่นของภาพเป็นสีตัว/ลาย, โน้มไปทางเทพนิยาย        |
| เพลง     | ขี้เล่นขึ้น                                       |
| เอกสาร   | อยากรู้อยากเห็น + ขี้เซา                          |
| โค้ด      | มียีนส์เกล็ดเสมอ, ซน + อยากรู้                     |
| ไฟล์บีบอัด  | ตะกละ โครงใหญ่ โน้มไปทางดึกดำบรรพ์               |

## รูปร่างที่เปลี่ยนตามการเลี้ยง (`composeBody`)

`รูปร่าง = f(ยีนส์โครงร่าง, ช่วงวัย, ไขมัน, ความฟิต)` — ยีนส์กำหนด "กรอบ" (ตัวใหญ่/เล็ก ขายาว/สั้น โครงหนา/บาง)
การเลี้ยงดูกำหนดว่าอ้วน ผอม หรือฟิตแค่ไหนในกรอบนั้น และย้อนกลับได้เสมอ
ช่วงวัย: เบบี้ → เด็ก → วัยรุ่น → โตเต็มวัย → ผู้อาวุโส (เบบี้หัวโตและขาสั้นกว่าตามสัดส่วน)
