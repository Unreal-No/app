## M1 — Living Pet

"เลี้ยงได้จริงบนจอ" — ส่วนที่เรียก Windows โดยตรงทดสอบในเครื่องพัฒนา (Linux) ไม่ได้ จึงแยกสถานะไว้

| งาน                                                | สถานะ                                                               |
| -------------------------------------------------- | ------------------------------------------------------------------- |
| การเติบโตตามเวลาที่ผู้ใช้อยู่หน้าจอ (เบบี้→เด็ก→วัยรุ่น→โต→อาวุโส) | ✅ unit test                                                        |
| หลายตัวบนจอ (สูงสุด 4) + ฟาร์มสำหรับตัวที่เหลือ             | ✅ ทดสอบในเบราว์เซอร์จำลอง                                            |
| แผงดูแลบนจอ: สถานะ อาหาร ขนม เล่น อาบน้ำ นอน ตั้งชื่อ     | ✅ ทดสอบในเบราว์เซอร์จำลอง · 🟡 การพิมพ์ชื่อบน Windows ยังไม่ได้ลองจริง       |
| จับคู่ผสมพันธุ์บนจอ → ไข่ที่จำพ่อแม่ได้, เปิดเผยยีนส์แฝงเมื่อโต     | ✅ ทดสอบในเบราว์เซอร์จำลอง                                            |
| เซฟรุ่น 2 + ย้ายจากรุ่นแรก + ซ่อมเซฟเสีย                  | ✅ unit test                                                        |
| เซฟลงไฟล์แบบ atomic + สำเนาสำรอง 3 รุ่น               | 🟡 ตรรกะผ่าน unit test · ยังไม่ได้ลองบน Windows จริง                     |
| เกาะ/เดิน/กระโดดขึ้นขอบหน้าต่าง, ร่วงเมื่อหน้าต่างหาย        | ✅ ตรรกะทดสอบด้วยหน้าต่างจำลอง · 🟡 การอ่านหน้าต่างจริงยังไม่ได้ลองบน Windows |
| ซ่อนเมื่อมีแอปเต็มจอ, เปิดพร้อม Windows, กันเปิดซ้ำ          | 🟡 build ผ่าน ยังไม่ได้ลองบน Windows จริง                                |

ยังไม่ได้ทำ (ย้ายไปรอบถัดไป): เซฟ SQLite + migration · global hotkey · ความทรงจำ/ความผูกพัน · หลายจอ

## M2 — Genetics Loop

ผังเครือญาติ · Monsterpedia (allele ที่ค้นพบ) · แท่นอัญเชิญจากไฟล์ (hash ฝั่ง Rust) ·
