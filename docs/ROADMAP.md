## M1 — Living Pet

แผงดูแลบนจอ (อาหาร ขนม ของเล่น อาบน้ำ) · เกาะขอบหน้าต่าง (EnumWindows) · เซฟ SQLite + migration ·
single-instance, autostart, global hotkey · ซ่อนเมื่อมีแอปเต็มจอ · ความทรงจำ/ความผูกพัน · หลายจอ

## M2 — Genetics Loop

ไข่และการฟัก · UI ผสมพันธุ์ · ผังเครือญาติ · Monsterpedia (allele ที่ค้นพบ) · แท่นอัญเชิญจากไฟล์ (hash ฝั่ง Rust) ·
การเติบโตตามวัย

## M3 — Habitats

โหมดฟาร์มเต็ม (ฟ้า/บก/น้ำ) · กลางวัน-กลางคืน ฤดูกาล สภาพอากาศ · สัตว์หลายตัว + ความสัมพันธ์ ·
การบิน/ว่ายน้ำบนจอ · Expedition · แขกป่า · เทศกาล

## M4 — Companion

เตือน/To-do/Pomodoro/Focus Egg → wellbeing → รับรู้บริบทเครื่อง → ปฏิทิน ICS → OAuth ปฏิทิน → คุยด้วย LLM + ความทรงจำ
(รายละเอียด: [COMPANION.md](COMPANION.md))

## M5 — Release

เสียง (สังเคราะห์จากยีนส์) · onboarding · หน้าตั้งค่า · ไทย/อังกฤษ · ปรับ performance · ตัวติดตั้ง + auto-update ·
code signing · ลง itch.io/Steam
