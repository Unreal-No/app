## M1 — Living Pet

"เลี้ยงได้จริงบนจอ" — ✅ ผู้ใช้ติดตั้งและลองบน Windows แล้ว ใช้ได้ครบ

| งาน                                                | สถานะ                            |
| -------------------------------------------------- | -------------------------------- |
| การเติบโตตามเวลาที่ผู้ใช้อยู่หน้าจอ (เบบี้→เด็ก→วัยรุ่น→โต→อาวุโส) | ✅ unit test                     |
| หลายตัวบนจอ (สูงสุด 4) + ฟาร์มสำหรับตัวที่เหลือ             | ✅ ลองบน Windows แล้ว             |
| แผงดูแลบนจอ: สถานะ อาหาร ขนม เล่น อาบน้ำ นอน ตั้งชื่อ     | ✅ ลองบน Windows แล้ว             |
| จับคู่ผสมพันธุ์บนจอ → ไข่ที่จำพ่อแม่ได้, เปิดเผยยีนส์แฝงเมื่อโต     | ✅ ลองบน Windows แล้ว             |
| เซฟรุ่น 2 + ย้ายจากรุ่นแรก + ซ่อมเซฟเสีย                  | ✅ unit test                     |
| เซฟลงไฟล์แบบ atomic + สำเนาสำรอง 3 รุ่น               | ✅ unit test + ลองบน Windows แล้ว |
| เกาะ/เดิน/กระโดดขึ้นขอบหน้าต่าง, ร่วงเมื่อหน้าต่างหาย        | ✅ ลองบน Windows แล้ว             |
| ซ่อนเมื่อมีแอปเต็มจอ, เปิดพร้อม Windows, กันเปิดซ้ำ          | ✅ ลองบน Windows แล้ว             |

ยังไม่ได้ทำ (ย้ายไปรอบถัดไป): เซฟ SQLite + migration · global hotkey · ความทรงจำ/ความผูกพัน · หลายจอ

## M2 — Genetics Loop

ไข่ การฟัก การเติบโต และการจับคู่ทำแล้วใน M1

| งาน                                                                    | สถานะ                                                           |
| ---------------------------------------------------------------------- | --------------------------------------------------------------- |
| บันทึกการอัญเชิญ (ไฟล์ละครั้ง วันละ 3 ครั้ง), สีจากรูป, ที่มา/วันเกิด/การกลายพันธุ์ของสัตว์ | ✅ unit test                                                    |
| สมุดสะสม (ลักษณะ/สายพันธุ์ที่พบ ตามความหายาก) + บันทึกเครือญาติ                   | ✅ unit test                                                    |
| แท่นอัญเชิญ: ลากไฟล์วาง + ปุ่มเลือกไฟล์, ไข่ลอยลงจากลำแสง, ไข่ฟอสซิล              | ✅ ทดสอบในเบราว์เซอร์ · 🟡 การลากจาก Explorer ยังไม่ได้ลองบน Windows |
| อ่านลายนิ้วมือไฟล์ฝั่ง Rust (SHA-256 หัว+ท้าย, รูปภาพส่งให้ WebView หาสี)           | ✅ unit test + build เป้า Windows                                |
| สมุดฟาร์ม: ฟาร์ม (รูปย่อ กรองถิ่น เรียก/สลับ) · เครือญาติ 3 รุ่น · สมุดสะสม          | ✅ ทดสอบในเบราว์เซอร์จำลอง                                        |
| ประกาศการค้นพบเมื่อไข่ฟัก/ยีนส์แฝงเปิดเผย, แผงดูแลบอกที่มาและวันเกิด                | ✅ ทดสอบในเบราว์เซอร์จำลอง                                        |

## M3 — Habitats

| งาน                                                                                | สถานะ                                        |

| สัตว์มีปีกบินเล่นครึ่งล่างของจอแล้วร่อนลงพื้น/ขอบหน้าต่าง; สัตว์น้ำอยู่คอนโดตู้ปลา (ห้องละตัว)             | ✅ unit test + ทดสอบในเบราว์เซอร์จำลอง         |
