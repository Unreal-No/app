# คู่มือทำชิ้นส่วน 3D (.glb) ให้ Mochimon

เปลี่ยน **หู เขา ปีก หาง** ของสัตว์ด้วยโมเดลที่ออกแบบเอง แล้วนำเข้าผ่านเมนู tray → **"นำเข้าชิ้นส่วน 3D (.glb)…"**
(หรือลากไฟล์ไปวางที่กล่องอัญเชิญในหน้า Creature Lab เพื่อลองก่อน)

ชิ้นจากไฟล์**แทนรูปทรงเดิม** แต่ระบบยีนส์ยังทำงานครบ:

- ลูกผสมยังได้หูจากพ่อ หางจากแม่ ตามยีนส์
- ยีนส์ขนาดยังขยายหรือย่อชิ้นส่วน
- **สีตัว ลายแต้ม ขนนุ่ม** ทาให้อัตโนมัติ ถ้าไม่อยากได้ ให้ใช้ material แบบ `texture`
- ท่าทางทำงานเหมือนเดิม: หูกระดิก ปีกกระพือ หางส่าย

ชิ้นที่ไม่มีในไฟล์ใช้ของเดิม ทำทีละชิ้นได้ ไม่ต้องครบทุกชิ้น

ไฟล์ตัวอย่างพร้อมใช้: [`tools/parts-kit/example-parts.glb`](../tools/parts-kit/example-parts.glb) มีหูรูปดาว เขาเห็ด ปีกผีเสื้อ และหางดอกไม้
สคริปต์ที่สร้างไฟล์นี้อยู่ที่ [`tools/parts-kit/example_parts.py`](../tools/parts-kit/example_parts.py) ใช้เป็นแม่แบบให้ GPT แก้ต่อได้เลย

## ข้อกำหนด

### 1. ชื่อ node

ใน Blender ให้สร้าง **Empty** 1 อันต่อชิ้น ตั้งชื่อเป็น `<ช่อง>.<รูปทรง>` แล้วเอา mesh ทั้งหมดของชิ้นนั้นไปเป็นลูกของ Empty นั้น
(ใช้ขีดล่างแทนจุดก็ได้ เช่น `ears_point`)

| ชื่อ node         | แทนรูปทรง     | ความหายากในเกม |
| --------------- | ------------ | -------------- |
| `ears.fin`      | หูครีบ         | rare           |
| `ears.floppy`   | หูตก          | uncommon       |
| `ears.long`     | หูยาว         | common         |
| `ears.point`    | หูแหลม        | common         |
| `ears.round`    | หูกลม         | common         |
| `ears.tuft`     | ขนหงอน       | uncommon       |
| `horns.antler`  | เขากวาง      | uncommon       |
| `horns.crystal` | เขาคริสตัล     | legendary ✨   |
| `horns.curved`  | เขามังกร      | rare           |
| `horns.nub`     | เขาตุ่ม        | uncommon       |
| `horns.spiral`  | เขายูนิคอร์น    | legendary      |
| `horns.trike`   | สามเขา+แผงคอ | rare           |
| `wings.bat`     | ปีกมังกร       | rare           |
| `wings.fairy`   | ปีกภูต         | legendary      |
| `wings.feather` | ปีกขนนก       | common         |
| `wings.fin`     | ครีบข้าง       | uncommon       |
| `tail.fan`      | หางพัด        | common         |
| `tail.fish`     | หางปลา       | uncommon       |
| `tail.flowy`    | หางพู่         | rare           |
| `tail.fluffy`   | หางฟู         | common         |
| `tail.nub`      | หางสั้นกุด      | common         |
| `tail.pom`      | หางปุย        | common         |
| `tail.spade`    | หางมังกร      | rare           |
| `tail.thick`    | หางไดโนเสาร์  | uncommon       |
| `tail.thin`     | หางแมว       | common         |
| `tail.twin`     | สองหาง       | legendary ✨   |

- **หู ปีก และเขา** เป็นคู่ซ้าย-ขวา ให้ทำ**เฉพาะฝั่งขวา (+X)** แล้วเกมจะสะท้อนอีกฝั่งให้เอง
- **เขาเดี่ยวกลางหน้าผาก** เช่น เขายูนิคอร์น ให้ต่อท้ายชื่อว่า `.center` เช่น `horns.spiral.center`
- ✨ = ได้จากการกลายพันธุ์เท่านั้น จึงเจอบนตัวสัตว์ได้ยาก

### 2. ตำแหน่ง ทิศทาง และขนาด (พิกัดใน Blender: Z ชี้ขึ้น)

| ชิ้น  | จุด origin ของ Empty | ทิศที่ชิ้นยื่นออกไป   | หน่วย 1.0 =       | ขนาดที่ดูพอดี  |
| --- | ------------------- | -------------- | ---------------- | ---------- |
| หู   | โคนหูที่แตะหัว          | ขึ้น (+Z)        | รัศมีหัว            | สูง 0.5–0.9 |
| เขา | โคนเขา              | ขึ้น (+Z)        | รัศมีหัว            | สูง 0.3–1.0 |
| ปีก  | ไหล่ (จุดต่อกับหลัง)     | ออกด้านข้าง (+X) | ความยาวปีกตามยีนส์  | ยาว ~1.0   |
| หาง | โคนหาง              | ไปด้านหลัง (+Y)  | ความยาวหางตามยีนส์ | ยาว ~1.0   |

- หน้าของสัตว์หันไปทาง **−Y** ของ Blender (ทิศเดียวกับ Front view)
- ส่งออกด้วยค่าเริ่มต้นของ Blender ("+Y Up" เปิดไว้) แล้วโปรแกรมจะแปลงแกนให้เอง

### 3. ชื่อ material (กำหนดสี)

| ชื่อ material ขึ้นต้นด้วย | สีที่ได้                                         |
| ------------------- | -------------------------------------------- |
| `skin`              | สีตัว + ลายแต้ม + ขนนุ่ม ตามยีนส์ (ค่าเริ่มต้นถ้าไม่ตั้งชื่อ) |
| `inner`             | สีชมพูด้านในหู/อุ้งเท้า                             |
| `accent`            | สีเขา/จะงอย (เรืองแสงได้ตามยีนส์)                 |
| `membrane`          | เนื้อปีก/ครีบ โปร่งแสงเล็กน้อย                      |
| `texture`           | **ใช้สี/ภาพจากไฟล์เอง** (ไม่เปลี่ยนตามยีนส์)         |

ต่อท้าย `_nofur` ถ้าไม่ต้องการขน เช่น `skin_nofur`

### 4. ขีดจำกัด

- ไฟล์ **.glb** (glTF แบบไฟล์เดียว) ขนาดไม่เกิน **20 MB**
- รวมทุกชิ้นไม่เกิน **200,000 สามเหลี่ยม** ถ้าเกิน ให้ใช้ Modifier **Decimate** ใน Blender ลดลงก่อน (ชิ้นละ 2,000–10,000 ก็สวยพอ)
- ตอนนี้ยังเพิ่มรูปทรง**ใหม่**ที่ไม่มีในตารางไม่ได้ ต้องแทนรูปทรงเดิมเท่านั้น
  รวมถึงหัว ลำตัว ขา และโมเดลทั้งตัว ซึ่งจะทำในรอบถัดไป

## ไฟล์จากเครื่องมืออื่น (trimesh, โปรแกรม 3D อื่นๆ)

- ไฟล์ที่ใช้แกน **Z ชี้ขึ้น** โดยไม่แปลงตอนส่งออก (เช่น สคริปต์ Python + trimesh ที่ GPT ชอบเขียน) ใช้ได้เลย
  เกมตรวจทิศของหู เขา และหาง แล้วแปลงแกนให้อัตโนมัติ และแผงจะบอกว่า "แปลงแกนให้แล้ว"
- material ที่ชื่อไม่ตรงกับตารางข้างบน เช่น `gold` จะ**ใช้สีจากไฟล์** และไม่เปลี่ยนตามยีนส์
- ตัวอย่างจริง: [`tools/parts-kit/fire-dragon-parts.glb`](../tools/parts-kit/fire-dragon-parts.glb) เป็นชุดมังกรไฟที่ GPT ทำด้วย trimesh
  มีหูใบไม้ เขาโค้ง เขาตุ่ม ปีกค้างคาว ปีกภูต หางมังกร และหางพู่

## ทำด้วย ChatGPT + Blender (ฟรี)

ChatGPT ส่งไฟล์ .glb ออกมาตรงๆ ไม่ได้ แต่**เขียนสคริปต์ Python ให้ Blender สร้างชิ้นส่วนแล้วส่งออก .glb ได้**:

1. ติดตั้ง [Blender](https://www.blender.org/download/) (ฟรี)
2. คัดลอกคำสั่งด้านล่างไปถาม ChatGPT แล้วแก้ส่วน **[ออกแบบ]** ตามที่อยากได้
3. เปิด Blender → แท็บ **Scripting** → กด **New** → วางสคริปต์ที่ได้ → กด **Run Script** (▶)
4. ได้ไฟล์ `my-parts.glb` → เปิด Mochimon → tray → **นำเข้าชิ้นส่วน 3D (.glb)…**
5. ถ้า Blender ขึ้น error ให้คัดลอกข้อความ error กลับไปให้ ChatGPT แก้

```text
เขียนสคริปต์ Python สำหรับ Blender 4.x ขึ้นไป (รันในแท็บ Scripting) ที่สร้างชิ้นส่วนตัวละครน่ารักสไตล์ตุ๊กตาขนฟู
แล้ว export เป็นไฟล์ GLB ชื่อ my-parts.glb ไว้ที่โฟลเดอร์เดียวกับไฟล์ .blend (หรือ Desktop ถ้ายังไม่ได้เซฟ)

[ออกแบบ]
- หูรูปใบไม้ แทน "ears.point"
- ปีกนางฟ้าแบบผีเสื้อ 2 ชั้น แทน "wings.fairy"
- หางเป็นพู่ขนนก แทน "tail.flowy"

ข้อกำหนดที่ต้องทำตามทุกข้อ:
1. ลบวัตถุเดิมในฉากทั้งหมดก่อน
2. แต่ละชิ้นสร้าง Empty 1 อัน ตั้งชื่อตรงตามที่ระบุ (เช่น "ears.point") และให้ mesh ทั้งหมดของชิ้นนั้นเป็นลูกของ Empty นั้น
3. แกนของ Blender: Z ชี้ขึ้น, หน้าของตัวละครหันไปทาง -Y
4. origin ของ Empty = จุดต่อกับตัว:
   - หู/เขา: โคนอยู่ที่ (0,0,0) งอกขึ้นไปทาง +Z สูงราว 0.6–0.9 หน่วย
   - ปีก: โคนที่ (0,0,0) กางออกไปทาง +X ยาวราว 1.0 หน่วย บางเป็นแผ่น
   - หาง: โคนที่ (0,0,0) ยื่นไปด้านหลังทาง +Y ยาวราว 1.0 หน่วย
   ทำเฉพาะฝั่งขวา (+X) ไม่ต้องทำซ้าย
5. ชื่อ material: "skin" (ส่วนที่เป็นขน/สีตัว), "inner" (ด้านในหู), "accent" (เขา), "membrane" (เนื้อปีก),
   หรือ "texture" ถ้าอยากให้ใช้สีที่กำหนดเองในไฟล์
6. รูปทรงโค้งมน นุ่มนวล ไม่มีมุมคม ใช้ smooth shading จำนวนสามเหลี่ยมชิ้นละไม่เกิน 10,000
7. export ด้วย bpy.ops.export_scene.gltf(filepath=..., export_format='GLB', export_yup=True)
```

ดูสคริปต์ตัวอย่างที่ทำตามข้อกำหนดนี้แล้วได้ที่ [`tools/parts-kit/example_parts.py`](../tools/parts-kit/example_parts.py)
(แนบไฟล์นี้ให้ ChatGPT ดูเป็นตัวอย่างด้วยได้)

## ทางเลือก: ภาพจาก GPT → AI สร้างโมเดล 3D

1. ให้ ChatGPT วาดภาพชิ้นส่วนเดี่ยวๆ บนพื้นหลังเรียบ เช่น "ปีกผีเสื้อสีพาสเทล มุมมองด้านหน้า พื้นขาว"
2. นำภาพไปเข้าบริการสร้างโมเดลจากภาพ (เช่น Meshy, Tripo) แล้วดาวน์โหลดเป็น .glb
3. เปิดใน Blender → ลดสามเหลี่ยม (Decimate) → จัดตำแหน่ง/ทิศตามตารางข้างบน → ทำ Empty ตั้งชื่อ → ตั้งชื่อ material → export .glb

ข้อควรระวัง:

- บริการสร้างโมเดลจากภาพบางเจ้าห้ามใช้เชิงพาณิชย์ในแพ็กเกจฟรี ตรวจเงื่อนไขก่อนถ้าจะขายเกม
- โมเดลจาก AI มักละเอียดเกินและสีติดมากับภาพ ถ้าอยากให้สีเปลี่ยนตามยีนส์ ให้ตั้ง material เป็น `skin` แทน `texture`
