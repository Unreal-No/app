# Companion — สัตว์เลี้ยงที่มีประโยชน์

เป้าหมาย: ไม่ใช่แค่ของเล่นฆ่าเวลา แต่เป็นเพื่อนร่วมโต๊ะทำงานที่ช่วยเตือน ดูแลสุขภาพ และอยู่เป็นเพื่อน
ส่วนที่ 1–2 (เตือน งาน โฟกัส สุขภาพ) **ทำแล้วใน M4a** ส่วนที่ 3–5 ยังไม่ได้ทำ — สถานะดูที่ [ROADMAP.md](ROADMAP.md)

## หลักการ

- **เปิดใช้เองทีละอย่าง** — ทุกสัญญาณ/การเชื่อมต่อปิดเป็นค่าเริ่มต้น
- **ข้อมูลอยู่ในเครื่อง** — ยกเว้นเมื่อผู้ใช้เลือกเชื่อมบริการภายนอกเอง (ปฏิทิน, LLM)
- **ไม่มี dark pattern** — ไม่มี streak ลงโทษ การเติบโตผูกกับนิสัยการทำงานที่ดี ไม่ใช่เวลาหน้าจอ
- **เล่นได้ครบโดยไม่ต้องต่อเน็ตและไม่ต้องมี LLM**

## 1. เตือนความจำ / To-do / Pomodoro (ออฟไลน์) — ✅ M4a

- **พิมพ์ภาษาพูด:** `14:30 ประชุม`, `อีก 20 นาที โทรหาแม่`, `พรุ่งนี้ 9 โมง ส่งงาน`, `บ่าย 2 ครึ่ง …`, `2 ทุ่ม …`,
  `ทุกวัน 12:00 กินข้าว`, `ทุกวันทำงาน 9:00 …`, `ทุกวันจันทร์ 10:00 …`, `25/12 …`, `tomorrow 8:30am gym`
  — แสดงผลแปลง ("→ เตือน “ประชุม” วันนี้ 14:30") ให้เห็นก่อนกด Enter เสมอ; ไม่มีเวลา = รายการงาน
  (`packages/core/src/companion/quickEntry.ts`)
- เตือนล่วงหน้า 10/5/1 นาทีเป็นคำพูด; ถึงเวลา สัตว์ตัวที่ขี้อ้อนที่สุดถือป้ายเดินมาข้างเคอร์เซอร์ ปุ่ม **รับทราบ · อีก 5 นาที · อีก 30 นาที**
  ท่าทางตามนิสัย (ขี้อ้อนกอดหัวใจ, ตัวซนกระโดดโลดเต้น, ขี้อายไม่เดินเข้ามาใกล้)
- การคำนวณ "ควรแจ้งอะไรในช่วงเวลานี้" เป็นฟังก์ชันบริสุทธิ์ (`alertsBetween`) — ไม่ซ้ำ ไม่ตกหล่น;
  เครื่องหลับข้ามเวลานัด → แจ้งครั้งเดียวว่า "เลยเวลามาแล้ว"; ปิดแอปไปแล้วเปิดใหม่ → ป้ายของนัดที่ค้างขึ้นมาเอง
- ตอนหน้าต่างสัตว์ถูกซ่อน (แอปเต็มจอ/ปิดการแสดง) ฝั่ง Rust (`alarms.rs`) แสดง Windows toast แทน
- **Focus Egg:** ระหว่างโฟกัสไข่บนจอฟักเร็วขึ้น 3 เท่า และจบรอบได้โบนัสการฟัก
- ยังไม่ได้ทำ: ลากข้อความใส่สัตว์ = ฝากโน้ต (ต้องทดลองการลากวางบน WebView2 ก่อน)

## 2. Wellbeing — ✅ M4a

- พักสายตา 20-20-20 (ป้ายนับถอยหลัง 20 วินาที), ดื่มน้ำ (นับแก้ววันนี้), ยืดเส้น (สัตว์ทำท่าให้ดู), ดึกแล้ว (สัตว์เข้านอน ชวนพัก)
- **ปิดทั้งหมดเป็นค่าเริ่มต้น** เปิดได้ในแท็บ "สุขภาพ" ของแผงผู้ช่วย
- นับเฉพาะเวลาที่ใช้เครื่องจริง: Windows บอกเวลาที่ไม่ได้แตะเมาส์/คีย์บอร์ด (`GetLastInputInfo` — ไม่มี keyboard hook);
  ลุกไปเกิน 5 นาที = ได้พักแล้ว ตัวนับเริ่มใหม่; ระหว่างโฟกัสเลื่อนดื่มน้ำ/ยืดเส้นไปตอนพัก
- **Body doubling:** ระหว่างโฟกัส สัตว์ตัวหนึ่งนั่งนิ่งข้างนาฬิกานับถอยหลัง ทุกตัวงดขอความสนใจ

## 3. ปฏิทินจริง

| เฟส | วิธี                                      | หมายเหตุ                                                          |
| --- | --------------------------------------- | ---------------------------------------------------------------- |
| 1   | สมัคร URL แบบ ICS                        | ใช้ได้ทั้ง Google/Outlook แบบอ่านอย่างเดียว ไม่ต้อง OAuth                 |
| 2   | OAuth: Google Calendar, Microsoft Graph | PKCE + loopback redirect, token เก็บใน Windows Credential Manager |

ระหว่างมีนัด: เข้าโหมดเงียบอัตโนมัติ (สัตว์นั่งนิ่ง ไม่เรียกร้อง ไม่มีคำพูด)

## 4. รับรู้บริบทเครื่อง (ในเครื่องเท่านั้น)

| สัญญาณ          | แหล่ง                           | ปฏิกิริยา                   |
| -------------- | ------------------------------ | ------------------------ |
| ไม่ได้ใช้งานนาน   | `GetLastInputInfo`             | สัตว์งีบ, เวลาของ needs หยุด |
| แอปเต็มจอ       | `SHQueryUserNotificationState` | ซ่อน/หยุดวาด               |
| หมวดแอปที่ใช้งาน  | ชื่อ process → หมวด              | ประชุม → เงียบ, เพลง → เต้น |
| แบตเตอรี่ต่ำ      | `GetSystemPowerStatus`         | ทำท่าหิวพลังงาน, ลดเฟรมเรต  |
| CPU ร้อน/ออฟไลน์ | ตัวนับของระบบ                    | เหงื่อตก / มองหาสัญญาณ      |

**ไม่ใช้ keyboard hook และไม่อ่านปุ่มที่พิมพ์** — ใช้เพียงเวลาของ input ล่าสุด

## 5. คุยด้วย AI (ตัวเลือก)

- ผู้ให้บริการ: Claude API (ผู้ใช้ใส่ API key เอง) หรือโมเดลในเครื่องผ่าน Ollama
- persona สร้างจากนิสัย + อารมณ์ปัจจุบัน + ความทรงจำ; เบบี้พูดอ้อแอ้ โตแล้วพูดเก่งขึ้น
- เครื่องมือที่โมเดลเรียกได้: สร้างเตือน, ดูนัดวันนี้, เริ่ม Pomodoro, จำเรื่องราว
- แสดงให้ผู้ใช้เห็นเสมอว่าข้อมูลอะไรถูกส่งออกไป; ปิดได้ทุกเมื่อ
- ไม่มี LLM: ใช้บทพูดสำเร็จรูปตามอารมณ์ (มีอยู่แล้วใน `apps/desktop/src/main.ts`)
