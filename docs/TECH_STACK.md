# Tech Stack

## สิ่งที่ต้องการจากเทคโนโลยี

1. หน้าต่างโปร่งใส ไร้ขอบ อยู่บนสุด **คลิกทะลุพื้นที่ว่าง** และไม่แย่ง focus
2. เรนเดอร์ 3D ที่ประกอบชิ้นส่วนจากยีนส์ได้ขณะรัน
3. เบาพอจะเปิดทิ้งไว้ทั้งวัน
4. เข้าถึง API ของระบบ (ตำแหน่งหน้าต่างอื่น, Taskbar, idle, แบตเตอรี่)
5. ทำ UI ผู้ช่วย/แชต/OAuth/เชื่อม LLM ได้ง่าย

## กลไก overlay บน Windows

- **หน้าต่าง** (`apps/desktop/src-tauri/tauri.conf.json`): `transparent`, `decorations: false`, `alwaysOnTop`, `skipTaskbar`, `focusable: false`, ขนาดเท่าจอหลัก **ลบ 1px** เพื่อไม่ให้ Windows มองว่าเป็นแอปเต็มจอ
- **คลิกทะลุ** (`src-tauri/src/overlay.rs`): หน้าต่างที่ตั้ง ignore-cursor-events จะไม่ได้รับ mouse event เลย จึงมีเธรดถามตำแหน่งเคอร์เซอร์จากระบบ ~60Hz เทียบกับ "hit shapes" ที่ frontend ส่งมา (`set_hit_shapes`) แล้วสลับ `set_ignore_cursor_events`
- **พื้นที่ยืน**: ขอบล่างของ work area ของจอ = ขอบบน Taskbar (`get_desktop_layout`)
- **ประหยัดพลังงาน**: วาด 30fps ปกติ และ ~12fps ตอนสัตว์หลับ/นั่งนิ่ง

## ข้อจำกัดที่รู้

- ตัวติดตั้งยังไม่ได้เซ็น → Windows SmartScreen จะเตือน (แก้ช่วง M5)
- การลากไฟล์ลงบนหน้าต่างที่กำลังคลิกทะลุทำไม่ได้ → ใช้ "แท่นอัญเชิญ" เป็นพื้นที่รับไฟล์โดยเฉพาะ
- ขนแบบ shell วาดผิวซ้ำหลายชั้น จึงมีตัวเลือกคุณภาพ ปิด/กลาง/สูง
