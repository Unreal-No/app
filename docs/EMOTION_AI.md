## Needs

- ลดลงช้าๆ ตามเวลา อัตราขึ้นกับนิสัย (ตะกละหิวเร็ว ขี้เซาเหนื่อยเร็ว ขี้อ้อนเหงาเร็ว)
- **มีพื้นต่ำสุด 0.08** — ไม่มีการอดตาย
- **ผู้ใช้ไม่อยู่ = เวลาหยุด** ไม่มีอะไรลดลง
- **ดูแลตัวเองได้บางส่วน:** เลียขนเอง (ความสะอาด) วิ่งเล่นเอง (ความสนุก) นั่งพัก (ความสบาย) ส่วนความหิวและความเหงายังต้องพึ่งผู้ใช้
  ทดสอบแล้วว่าสัตว์ที่ไม่มีใครดูแลทั้งวันใช้เวลาเรียกร้อง (ขออาหาร/เรียกร้องความสนใจ) ไม่ถึงครึ่งของเวลา

## Emotion

เหตุการณ์ (ลูบ ให้อาหาร เล่น อุ้ม ทำตก ตกใจ ถูกเมิน …) มีผลพื้นฐานต่อ valence/arousal แล้ว**ถูกปรับด้วยนิสัย**:

- ถูกอุ้ม: ตัวขี้อ้อนดีใจ ตัวขี้อายใจหายและตื่นตัวสูง
- อาบน้ำ: ตัวซนไม่ชอบ
- ถูกเมิน: ตัวขี้อ้อนเสียใจมากกว่า

อารมณ์ไหลกลับสู่ค่าพื้นฐาน (ครึ่งชีวิต ≈ 1 นาที) ซึ่งคำนวณจากความพอใจของ needs + mood
ป้ายอารมณ์: ร่าเริง สบายใจ ตื่นเต้น สงสัย อาย ง่วง หิว เหงา เบื่อ งอน เศร้า ตกใจ
แต่ละป้ายผูกกับสีหน้า (`packages/creature/src/anim/expression.ts`) และท่าทาง/หาง/หู (`anim/animate.ts`)

## Personality = ยีนส์ + การเลี้ยงดู

- ค่าตั้งต้นมาจากยีนส์ `temper.*`
- ประสบการณ์สะสมเลื่อนนิสัยได้ไม่เกิน ±0.25 ต่อแกน: ลูบบ่อย → ขี้อ้อนขึ้น ขี้อายลดลง, ทำตก/ทำให้ตกใจ → ขี้อายขึ้น
- **วัยเด็กไวกว่า** (plasticity: เบบี้ ×3, เด็ก ×2.2, วัยรุ่น ×1.5, โต ×1, อาวุโส ×0.6)

## Behaviour: Utility AI

ทุกครั้งที่พฤติกรรมเดิมหมดเวลา ระบบให้คะแนนพฤติกรรมทั้ง 10 แบบจาก `needs × นิสัย × บริบท`
แล้วสุ่มถ่วงน้ำหนักจากกลุ่มคะแนนสูง (ไม่เลือกอันดับ 1 ตายตัว จึงไม่ดูเป็นหุ่นยนต์)

| พฤติกรรม         | ตัวขับหลัก                                 |
| --------------- | --------------------------------------- |
| นอน             | เหนื่อย², นาฬิกาชีวิต (ยีนส์ chronotype), ขี้เซา |
| เดินเล่น          | อยากรู้อยากเห็น, ความตื่นตัว                  |
| เดินตามเคอร์เซอร์  | ขี้อ้อน, เหงา (ลดลงถ้าขี้อาย)                 |
| เรียกร้องความสนใจ | เหงา × ขี้อ้อน                             |
| วิ่งพล่าน          | เบื่อ × ขี้เล่น                              |
| หลบ             | ขี้อาย × เคอร์เซอร์อยู่ใกล้                    |
| ขออาหาร         | หิว² × ตะกละ (จำกัดเพดานไว้)               |
| เลียขน           | ความสะอาดต่ำ                             |
| นั่ง / ยืนเฉย      | ค่าพื้นฐาน, เพิ่มในโหมดเงียบ                  |

บริบทที่ใช้: เวลาท้องถิ่น, เคอร์เซอร์อยู่ใกล้หรือไม่, ผู้ใช้กำลังใช้งาน, **โหมดเงียบ** (ประชุม/โฟกัส → ไม่เรียกร้อง)

- ความทรงจำเชิงเหตุการณ์ + ไดอารี่รายวัน
