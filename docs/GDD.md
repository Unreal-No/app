# Game Design Document — Mochimon

## แนวคิดหลัก

สัตว์เลี้ยงเสมือนบนหน้าจอ Desktop แนว Tamagotchi × Monster Farm **ไม่มีการต่อสู้**
แกนของเกมคือ ความน่ารัก · การเลี้ยงดู · การผสมพันธุ์ลุ้นยีนส์ · ความผูกพัน · และการเป็นเพื่อนที่มีประโยชน์ระหว่างทำงาน

**หลักการออกแบบ**

1. **ไม่กดดัน** — ไม่มีความตาย ไม่มีบทลงโทษเมื่อหายไป ค่าความต้องการหยุดลดเมื่อผู้ใช้ไม่อยู่ และสัตว์ดูแลตัวเองได้บางส่วน
2. **ไม่รบกวนงาน** — คลิกทะลุพื้นที่ว่าง ไม่แย่ง focus มีโหมดเงียบ ซ่อนเองเมื่อมีแอปเต็มจอ
3. **ทุกตัวไม่ซ้ำกัน** — หน้าตา นิสัย และความชอบมาจากยีนส์ + การเลี้ยงดู
4. **มีประโยชน์** — เตือนนัด พักสายตา โฟกัสงาน (ดู [COMPANION.md](COMPANION.md))
5. **ข้อมูลอยู่ในเครื่อง** — ไม่มีเซิร์ฟเวอร์ ไม่ส่งไฟล์หรือพฤติกรรมการใช้งานออกไปไหน

## วงจรการเล่น

```
ได้ไข่ ──► ฟัก ──► เลี้ยงดู (อาหาร ขนม ลูบ เล่น อาบน้ำ นอน) ──► โต/นิสัยก่อตัว
  ▲                                                              │
  └──── ผสมพันธุ์ / อัญเชิญจากไฟล์ / สำรวจ / ไข่โฟกัส ◄────────────┘
```

## โหมดฉากหลัง (Toggleable Habitat)

| โหมด       | ลักษณะ                                     | สถานะ                       |
| ---------- | ----------------------------------------- | --------------------------- |
| 1. กลมกลืน  | ไม่มีฉาก สัตว์เดินบน Taskbar / เกาะขอบหน้าต่าง   | Taskbar ทำแล้ว, ขอบหน้าต่าง M1 |
| 2. มุมพักผ่อน | ไดโอรามาเล็กที่มุมจอ (ทุ่งหญ้า เกาะเมฆ ใต้น้ำ หิมะ) | ทำแล้ว (เลือกจากเมนู tray)     |
| 3. ฟาร์มเต็ม | หน้าต่างแยก ไดโอรามาตัดขวาง 3 ชั้น ฟ้า/บก/น้ำ    | M3                          |

## สภาพแวดล้อม: บก – ฟ้า – ใต้น้ำ

ถิ่นอาศัยของสัตว์มาจากชิ้นส่วนร่างกาย (`deriveHabitat` ใน `packages/core/src/genetics/express.ts`):
ปีกบินได้ → ฟ้า, ครีบ/หางปลา → น้ำ, เดินได้และว่ายได้ → สะเทินน้ำสะเทินบก, นอกนั้น → บก
ฉากใช้เวลา ฤดูกาล และ (ถ้าเปิด) สภาพอากาศจริง รวมถึงเทศกาลไทย เช่น สงกรานต์ ลอยกระทง

## การหาไข่

1. **อัญเชิญจากไฟล์** — ลากไฟล์ใดก็ได้มาสร้างไข่ (ดู [GENETICS.md](GENETICS.md))
2. **ผสมพันธุ์** — ข้ามสายพันธุ์ได้ทุกคู่
3. **Expedition** — ส่งสัตว์ออกสำรวจ 15 นาที–8 ชม. ได้ไข่ ของ ฟอสซิล (ต้องบูรณะ) หรือวัตถุเทพนิยาย (ต้องมีเงื่อนไข เช่น คืนพระจันทร์เต็มดวง)
4. **Focus Egg** — ไข่ฟักด้วยเวลาโฟกัสงาน (Pomodoro)
5. **แขกป่า** — สัตว์ป่าเดินผ่านจอ ผูกมิตรด้วยอาหารที่ถูกใจ
6. **ของขวัญรายวัน** — ไม่มี streak ลงโทษ
7. **Gene Card** — ส่งออกสัตว์เป็นรหัส/รูปการ์ดเพื่อแลกไข่กับเพื่อนโดยไม่ต้องมีเซิร์ฟเวอร์
